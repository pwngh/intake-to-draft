# Intake to draft

This planned Python service turns invented family law intake transcripts into demonstration petition drafts with a source line for each filled value.
It will use LangGraph for extraction, validation, human review, and template filling, with local retrieval and self-hosted Langfuse traces.
This repository is currently a bootstrap only; it contains no working service, legal forms, or legal advice.

Implementation has not started. There is no runnable demo or test command yet.

Portfolio project for Preston Neal.
